# Özelleştirme

1. index.html içindeki demo markasını ve örnek ihtiyaç akışını gerçek bilgilerle değiştirin.
2. assets/css/style.css başındaki fildişi, pudra ve burgundy renklerini markanıza uyarlayın.
3. Mevcut JPG fotoğrafları kullanmaya devam edebilir veya hakları doğrulanmış görsellerle değiştirebilirsiniz.
4. Tedavi, sonuç, güvenlik, ekip, fiyat ve ürün iddiasını doğrulamadan yayınlamayın.
5. npm test, npm run lint ve npm run build sonrasında mobil/masaüstü görünümü kontrol edin.
