# AK Beauty

Beauty stüdyoları için sakin, görsel ağırlıklı ve erişilebilir GitHub Pages şablonu.

**Canlı demo:** https://ak-hosting.github.io/ak-beauty/<br>
**Lisans:** MIT

> Kurgusal demo markasıdır; gerçek bakım, tedavi veya randevu sistemi değildir.

## Özellikler

- Fildişi, pudra ve burgundy tonlarında bağımsız editorial tasarım
- Repository içindeki mevcut JPG fotoğraflar korunmuştur
- Kişisel veri istemeyen yerel demo danışma aracı
- Harici UI kütüphanesi, analiz, çerez veya form gönderimi yok
- Mobil menü, yasal sayfalar, robots ve sitemap

Yerel önizleme: `python3 -m http.server 8000`

Kontroller: `npm test`, `npm run lint`, `npm run build`

Üretime uyarlarken hizmet kapsamı, uzmanlık, ürün, süre, ücret ve sağlıkla ilişkili tüm iddiaları yetkili kaynaklarla doğrulayın.
